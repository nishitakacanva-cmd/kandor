# Kandor V2 image and evidence register

Access date: 2026-10-29 (Asia/Calcutta).

The original page used generic Pexels food photographs for a handful of products. Those URLs were removed in V2 because they did not prove the exact brand, variant or pack size. V2 restores only matched retail/brand listing packshots and uses a quiet category illustration for catalogue entries that still need an exact asset.

Current runtime coverage: 74 of 74 catalogue IDs have a mapped packshot URL. Five pitch packshots supplied by the user are stored locally under `assets/packshots/`: India Gate, True Elements Whole Amaranth, Amul Shakti, Parle-G, and MTR Vermicelli. The True Elements item is labelled as Whole Amaranth because that is what the uploaded pack shows; it is not labelled as flour.
